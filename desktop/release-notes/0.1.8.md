# XiaoWei 0.1.8

## 新增

- Agent 支持在 macOS 沙箱中执行 Bash 命令，并提供 Glob 文件查找和 Grep 内容搜索。
- Agent 支持交互问答、文件写入权限申请和持久任务清单，可在聊天中查看任务进度。
- Agent 支持网页搜索与抓取，可在设置中选择 Bing、Tavily、Brave 或 Serper 搜索源。
- Agent 支持按需加载用户和项目技能，复用技能中的操作说明。
- 剪贴板图片详情支持使用系统图片查看器打开。

## 优化

- 调整聊天消息、思考过程和工具调用的展示，将过程内容合并为可折叠分组，改善消息布局和间距。
- 优化 Quick Chat 窗口保留与 Dock 显隐，减少搜索和设置窗口切换时的干扰。
- 剪贴板分类按最近修改时间排序，改善分类导航和记录保存体验。
- 增加连接诊断日志，便于关联客户端与服务器的连接、断线原因和自动重连过程。

## 修复

- 修复切换搜索时意外抬起设置窗口的问题。
- 修复聊天会话选中状态与悬停状态不易区分，以及消息底部信息的位置问题。
- 修复编辑剪贴板记录时使用次数丢失的问题。
- 修复账号操作取消、凭据保存和会话恢复过程中的状态问题，改善云连接异常反馈。
