# Tray、Dock 与窗口焦点

本文说明 macOS 桌面端的窗口管理。主窗口的模式、图钉与失焦行为见 [Quick Chat](chat-ui.md#产品入口与窗口交互)，快捷键配置与 Tray 菜单期间的原生交接见 [桌面快捷键](../../docs/shortcuts.md)。

## Tray

左键和右键菜单中的「搜索」共用当前模式的唤起入口。「剪贴板」和「快速对话」切换到对应模式。右键菜单还提供「设置」和「退出」，模式入口展示当前绑定的快捷键，设置使用 `⌘,`。

正式包使用 `tray.png`，开发态使用它的水平镜像 `tray-dev.png`。两者的 16 px 与 32 px Retina 模板图位于 [`resources/logo-sizes/`](../resources/logo-sizes/)。

## Dock 显隐与轮换

- macOS Dock 图标只计入普通窗口和 [Sparkle 原生更新窗口](macos-packaging-and-updates.md)。目前普通窗口只有设置窗口。搜索、剪贴板和 Quick Chat 共用 Launcher，三种模式均排除在 Dock 显隐和窗口轮换之外。
- 普通窗口首次显示后计入，最小化期间保留，销毁后移出。设置窗口关闭时销毁，加载失败也会销毁。最后一个计入的窗口关闭后隐藏 Dock 图标。用户固定在 Dock 中的启动图标由 macOS 管理。
- Dock 点击和 macOS 二次启动复用普通窗口激活入口。应用从外部激活时优先显示最近聚焦的普通窗口，应用内连续激活时按注册顺序轮换，选中最小化窗口时先恢复。候选为空时结束处理。
- `ordinary-windows.ts` 串行协调实际显隐与目标状态。Electron 44.3.0 可能忽略 `dock.show()` 后一秒内的 `dock.hide()`，因此隐藏后若图标仍可见，会在一秒后按最新窗口状态重试。
- Electron ready 后初始化 Dock 状态。开发态在每次 `dock.show()` 完成后重新设定 `icon-512.png`，正式包使用打包图标。

## 焦点会话与隐藏原因

macOS Launcher 从隐藏到显示时捕获一次唤起来源。来源可以是本应用聚焦的具体窗口，也可以是外部应用及其窗口快照。重复点击 Tray 或在主窗口内切换模式沿用同一次来源。

在 macOS 上，先用 `showInactive()` 将 Launcher 显示在当前 Space，再调用 `focus()`。窗口创建时一次性设置跨 Space 可见，并传入 `skipTransformProcessType: true`，避免 Electron 因配置跨 Space 而显示 Dock 图标。

| 主窗口交互 | 焦点处理 |
| --- | --- |
| 快捷键收起、关闭窗口 | 收起后恢复本次唤起来源 |
| 主动切换到其他窗口 | 由图钉决定失焦后是否收起，收起时结束本次焦点会话 |
| 打开设置 | 将焦点交给设置窗口 |
| 打开搜索结果中的应用、URL 或更新界面 | 将焦点交给打开的目标 |
| 复制计算结果等无需打开目标窗口的操作 | 收起后恢复本次唤起来源 |
| 选择剪贴板记录 | 先复制，再收起并确认焦点恢复，确认成功后按设置自动粘贴 |
| 退出应用 | 结束焦点会话，释放窗口快照 |

同应用来源直接恢复对应的 Electron 窗口。外部来源优先恢复原窗口，缺少辅助功能权限或原窗口无法恢复时按平台能力退回到应用级激活。新的唤起会话、用户切换到其他应用或恢复超时都会取消尚未完成的归还。剪贴板恢复失败时保留已复制内容，自动粘贴需要确认焦点恢复。平台接口见 [平台绑定](../../crates/xiaowei-rust/docs/platform.md#模块边界)。

针对工作区或正式包的窗口、焦点和 Dock 状态查询入口见 [运行实例检查](inspect.md)。
