# 第二部分：模型、智能体、对话归档

## 范围与前置

- 依赖第一部分的设置窗口、类型／默认值／校验／通知模块及真实数据适配；开始接入前还需取得这三页 Storybook UI 的用户确认。继续复用现有 `ModelSettings`、`ModelCatalog`、`AgentSettings`、`ArchiveSettings`；`SettingsPreview.tsx` 不进入产品调用链。
- 当前仓库尚无可用的模型推理／本地模型下载服务、Agent 运行时和会话归档后端。计划包含建立所需业务能力，不能只把配置存进 Settings 或返回模拟模型列表就宣称完成。扩展页与剪贴板旧数据离线迁移不在本切片。账号登录／云连接、剪贴板图片内容提取和自动更新仍按用户要求暂缓；Storybook 保留预览，第二部分也不接入这些业务或入口。图片生成模型配置与图片内容提取是不同能力。

## 实施顺序

1. **模型数据与凭据边界。** 在 Rust `xiaowei-storage/src/settings` 模块和 `Settings` 契约中定义全局默认／轻量／图片模型、思考模式、本地启用与选择等键；提供方和每个模型的上下文、最大输出、图片能力按稳定 ID 管理。提供方预设锁定地址及协议，自定义项可编辑；连接信息变化后的模型列表要显式重新拉取，已添加模型和手动覆盖按已确认的 UI 语义合并。新建 `desktop/src/main/credentials.ts` 统一密钥写入和读取：API Key 不以明文进入设置存储、日志或读取响应，主进程使用系统保护能力保存密文，只向 renderer 返回“已配置”状态；系统不支持安全保存时明确报错，不降级为明文。Linux 等平台需核查加密后端，不能把弱保护的 fallback 当作安全存储。
2. **远程提供方操作。** 在 `desktop/src/main/model-providers.ts` 和按职责划分的业务契约中实现 `openai-completions`、`openai-responses`、`anthropic-messages` 的连接／模型发现适配，装配到 `desktop/src/main/app/gateway.ts` 并由产品容器调用；每种协议分别核对其列表接口、认证、URL、分页、错误和可选上下文元数据，不能假设返回格式一致。选择弹窗执行搜索和多选，手动添加模型 ID 后可编辑图片支持、上下文窗口和最大输出 token；测试超时、空列表、取消、重新获取保留本地配置及删除提供方时全局模型引用清理。图片生成测试须是真实能力验证，不能由请求列表推断；实际第三方调用可能产生费用，仅在用户主动操作时发起。
3. **本地模型。** 为预览中的下载、校验、解压、失败重试、目录打开和切换接入真实模型管理／运行服务，检查磁盘与内存状态，启用设置影响后续使用。先核对旧版模型资源、文件生命周期和失败恢复，再确定实现与契约；不把预览中的下载进度写成假进度。
4. **智能体。** 在设置模块保存工具调用上限与网络搜索源；在 `desktop/src/main/agent-search.ts` 建立搜索源适配与测试，Tavily、Brave、Serper 的 Key 复用 `credentials.ts` 的边界，删除当前源 Key 时回退到 Bing。搜索源测试调用真实适配器并处理限流／鉴权错误；调用上限必须由未来 Agent 执行循环强制执行，而不只是下拉框数值。若 Agent 运行时尚未提供，先实现其消费设置的接口及业务测试，本页运行效果待该服务就绪后验收。
5. **对话归档。** 先建立或接通持久化会话领域服务和相应业务契约，再把归档／清理期限交给后台调度，并让列表搜索、恢复、永久删除作用于同一会话数据；`desktop/src/renderer/src/components/settings/SettingsPage.tsx` 负责调用该服务和展示操作结果。当前仓库没有会话模块，具体存储模块路径待建立该领域边界时确定，不能把会话表直接塞进通用 `xiaowei-storage` KV。按当前 `ArchiveSettings.tsx` 的空／加载／确认状态处理失败和重试；删除需要明确数据库记录及关联资源的生命周期。没有实际会话服务时不得展示伪造归档条目或报告该页已完成。
6. **联调与收尾。** 将产品容器从第一部分的占位范围扩充为这三页，保留 Storybook fixture 作为 UI 验收资料。跨窗口及重启验证模型默认选择、凭据可用性、Agent 限额与搜索源、会话归档调度；更新本事项长期说明与 Outcome，删除本 Plan。

## 验证

- 模型协议使用本地 mock server 验证不同格式、错误、空列表和超时，不在 CI 中调用或计费第三方服务；凭据读回仅能得到配置状态，日志不包含 Key。模型删除／重新获取不能产生悬空默认引用，手工数值经过范围校验。
- Agent 测试 Key 删除回退、真实搜索适配器的错误与工具调用上限；归档测试期限触发、搜索／恢复／删除及附件清理。运行 `pnpm contracts:check`、`pnpm --dir desktop check`／`test`、Storybook 构建、受影响 Rust 测试与 napi 构建。实际网络、文件下载和原生窗口交互在用户启动当前工作区实例后验收。
- 完成标准：三页展示持久化的实际状态，每个可操作入口对应真实能力；模型密钥受保护，归档操作不会误删数据。任何依赖的推理、Agent 或会话能力尚未落地时，不把整个第二部分标记完成。
