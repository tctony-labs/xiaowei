# 迁移 Launcher 搜索入口

## Why

用可唤起的搜索框替代初始化欢迎页，建立后续搜索能力共用的桌面入口。参考旧项目的交互，不引入内部后台依赖。

## What

本次范围是搜索框外观及窗口显示、隐藏、聚焦、快捷键与输入法处理。暂不迁移搜索数据源、结果列表、模式切换、剪贴板或 Agent 功能，也不引入 Rust。

## How

- 主窗口为 800 × 71 的无边框透明圆角搜索框，不可调整大小，保持置顶。顶部 16px 区域可拖动；浅色和深色随系统切换。
- macOS 使用旧项目的默认快捷键 `Command+Alt+Space`；其他平台使用 `Control+Alt+Space`。聚焦时再次按下隐藏，否则显示并聚焦。在鼠标所在显示器的工作区上方居中唤起。
- 首次等待 `ready-to-show` 才显示；失焦隐藏，开发者工具打开时保留窗口以便调试。关闭窗口隐藏而非销毁；退出应用正常销毁并释放快捷键。快捷键被占用时输出错误，macOS 可从 Dock 再次唤起。
- 搜索框初次挂载聚焦，再次聚焦时全选已有输入。Esc 清空并隐藏；输入法组合期间不截获 Esc。
- preload 只暴露 `launcher.hide()`，主进程校验调用来自 launcher 主 frame；不暴露任意 IPC。
- 输入已由后续 [全局搜索事项](2026-09-16-migrate-search.md) 接入 Rust 核心与结果列表；搜索不请求网络服务。
- Electron/Node 只承载窗口、快捷键及 IPC。原有 Rust 业务逻辑不迁写为 Node；需要接入具体业务时，再讨论 Rust 模块复用及 napi-rs 集成方案。

## Current work

用户于 2026-09-16 确认当前搜索框样式：使用透明 Logo，右内边距 16px。组件层的 Esc 清空关闭、组合输入期间 Esc 不关闭、重新聚焦全选已在 Storybook 中验证 PASS；组合输入测试使用合成事件，不等于原生输入法验收。

已给桌面 Vite 增加与 Storybook 一致的 100ms 轮询。用户重启后确认窗口显示恢复正常，旧实例的 720 × 76 尺寸已更新为 800 × 71；Agent 未执行冷启动。全局快捷键、原生失焦隐藏、拖动、屏幕定位和真实输入法仍待运行验收，事项保持实施中。

视觉样例与桌面共用 LauncherSearchBar，样式参数以旧版为基础，不保留此前新增的搜索图标和 Esc 标签；完整场景与验收流程见 [UI 对齐](../../../docs/ui-alignment.md)。桌面与 Storybook 构建、`just check` 通过。
