## How

Storybook 菜单精简为 30 个展示场景，保留默认页、关键弹窗与必要状态；主题使用工具栏切换，次要变体使用 Controls。30 个原交互检查迁入 settings 同目录的 8 个 `*.test.tsx`，通过 Vitest / Testing Library 独立运行。Storybook `play` 只做视觉状态初始化。

每个选定页面先核对旧版样式及交互，按 [Renderer UI 开发](../../../desktop/src/renderer/README.md) 制作预览。现有公开／本地组件优先复用，不引入旧版私有 `@tencent` UI 依赖。登录、模型下载、联网测试、系统设置和文件操作在预览中仅模拟。

当前预览位于 `desktop/src/renderer/src/components/settings/`：

- `SettingsLayout`、`SettingsTabLayout`、`SettingCard`、`SettingRow` 与选择器、开关、快捷键录制沿用旧版结构。侧栏 207px，菜单项间距按用户反馈由 2px 调整为 6px，分隔选中与 hover 背景；标题栏最小 44px，内容左右 24px，卡片圆角 12px，设置行最小 42px。旧版窗口尺寸参考 `xiaowei/studio/src/window/config.rs`，为 800 × 600，可调整大小。Storybook 的所有 Settings 场景使用 800 × 600 viewport；窗口在画布内水平、垂直居中，视口外框与弹窗遮罩统一按 12px 圆角裁切，空间不足时保持尺寸并滚动查看，弹窗也限制在该视口内。
- 左上角红黄绿窗口按钮仅在 `SettingsPreview` 中模拟外观，不执行关闭、最小化或全屏操作。产品独立设置窗口在 macOS 使用 `hiddenInset` 原生标题栏按钮，不渲染这些模拟元素。
- 七个页面组件接收 props 和回调；`SettingsPreview.tsx` 只供 Storybook 组合展示，提供内存数据、模拟异步返回与错误，不连接 Electron／Rust／网络，不写配置或系统剪贴板。
- 相邻 `*.stories.tsx` 按 Window、General、Shortcuts、Clipboard、Models、Agent、Archive、About 分组。Storybook 可切页，也可直接选择弹窗或状态；明暗沿用当前项目主题变量，背景等设置专用样式放在 `settings.css`。没有更改产品正在使用的共享组件。
- 模型配置于 2026-09-22 按用户要求参考本机 dsh web（`http://127.0.0.1:3080/`）调整；已通过现有 Chrome 核对添加预设／自定义提供方的交互，保留本项目弹窗与视觉样式。提供统一的“添加”入口，弹窗内提供方下拉首项为“自定义”且默认选中，列表标记类型。预设提供方的地址、协议只读，自定义提供方可以编辑；预览包含 DeepSeek、OpenAI、Anthropic 三个预设，不复制 dsh 的全部提供方目录。
- 协议标识及显示统一为 `openai-completions`、`openai-responses`、`anthropic-messages`；Responses 保留自动／仅 HTTP 传输选项。获取模型后在弹窗中搜索、多选或全选当前搜索结果，点击添加合入配置列表；重复模型标为已添加，不覆盖已有配置。列表行展开编辑图片支持、上下文窗口、最大输出 token，文本支持默认开启且不显示开关。最大输出 token 提供 4K／8K／16K／32K／64K／128K 快捷档位与自定义正整数，不用原生数字步进框；档位不代表各模型支持的上限。右侧删除，底部支持手动添加模型 ID。连接信息或 Key 变化清空关联模型配置，可重新获取或手动添加。获取中禁用保存；获取失败、空结果、取消选择不会清空已有列表。
- 默认思考强度紧接默认模型下方；未选择默认模型时禁用并提示“请先选择默认模型”。选择后仅展示该模型思考强度映射中支持的档位，不支持推理时禁用并显示“不支持推理”；切换模型后清除不再支持的默认档位。
- 提供方区域只管理连接与模型配置，不维护“当前提供方”或提供方级默认模型；新增或修改提供方不自动切换全局默认模型，全局选择由页面上方的默认模型选择器显式完成。
- 获取模型时立即在提供方弹窗上叠加选择弹窗，加载、失败重试和空结果均在顶层呈现；底层保留表单及展开状态并暂停交互，Esc／回车仅作用于顶层。取消后迟到的响应不重新打开弹窗。搜索与全选位于同一行，选择数量仅在添加按钮显示。
- 模型列表响应支持可选上下文上限；接口未返回且未手动配置时显示“上下文窗口：未设置”，不推测数值。单模型手动覆盖优先，否则使用接口返回值；重新获取同一连接的列表保留仍存在模型的手动配置。模型目录、下载和网络校验均为模拟，不使用真实凭据或发送请求。
- 关于页采用当前项目 Logo、示例版本，版权通过可选 prop 提供，本次预览不显示旧 Tencent 版权。
- 不提供扩展导航或占位页；剪贴板增加“清理全部”行，位于已用存储空间下方，包含清理中、成功及失败重试状态。第一阶段产品通过应用菜单“设置…”（Cmd+,）打开独立 800 × 600 窗口，复用四页组件；其余三页仍仅供预览。

需要明确区分的边界：

- 第一阶段设置由 Rust `xiaowei-storage/src/settings` 维护默认值、校验、旧 `setting.*` 数据读取与逐项写入；`Settings` Gateway 提供有类型的完整快照、单项更新和提交后变更事件。Electron 主进程通过 Gateway 读取设置，并通过回调执行系统操作；系统操作或持久化失败时尝试恢复此前系统状态。底层 SQLite `meta` 表只作为 Rust 实现，对外的通用 JSON KV 契约名为 `KeyValue`。通用 KV 不允许读写 `setting.*` 和 `migration_v2.*`，业务模块通过 `Settings` 更新设置，保证校验和通知。产品 `SettingsPage` 先订阅再读取快照，更新失败时重新读取已提交状态。Launcher 与设置窗口响应主题变更；Launcher 在设置变更后重新查询当前搜索词。应用菜单打开可重用的独立设置窗口，并提供原生“关闭窗口”命令（macOS 为 Cmd+W）；macOS 使用原生 `hiddenInset` 标题栏，Storybook 模拟按钮不进入产品。
- 剪贴板选取走 `Clipboard.Select`，成功复制后隐藏 Launcher；自动粘贴未配置时默认关闭，已显式保存的值保持原样。用户在 macOS 手动开启时立即请求辅助功能权限，之后获得授权才会在选取时发送 Command‑V；尚未授权时仍完成复制。右键复制只走 `Clipboard.Copy`。容量显示统计共享数据库（含 WAL）及剪贴板附件；手动“清理全部”与按期限清理共用只删除普通记录的保护条件，并释放附件。

- “清理全部”是新增入口，旧版 `ClipboardTab` 没有；用户于 2026-09-20 明确仅制作设置 UI 预览。业务语义为复用自动清理规则，将清理截止时间设为点击时的当前时刻，清理该时刻之前的全部普通数据，而非按保留天数回推截止时间。普通数据须同时满足未收藏、无备注、无标签等保护标记；任一保护标记存在即保留。当前仅有预览，第一部分计划实现业务；不得调用现有语义不同的 `clearHistory` API，见 [剪贴板后续事项](2026-09-17-migrate-local-clipboard.md)。
- 旧版剪贴板数据库及附件迁移改为离线一次性迁移，对最终用户不可见；产品设置和 Storybook 均不提供迁移入口、进度或结果展示。迁移实现仍待后续工作，不因移除 UI 而视为已完成迁移，见 [剪贴板后续事项](2026-09-17-migrate-local-clipboard.md)。
- 旧版账号使用微信登录、UIN 和云连接状态；用户于 2026-09-23 决定暂缓账号登录和云连接，Storybook UI 保留用于后续设计，第一部分产品接入跳过整个账号区，不显示模拟账号或无效操作。
- 旧版快捷键包含快速对话及自定义录制；当前产品没有快速对话目标行为，用户决定暂缓。完整 Storybook UI 保留，本期产品隐藏该行，不注册或保存无动作快捷键。
- 关于页的旧品牌资源、Tencent 版权不直接照搬；自动更新和检查更新入口暂缓，Storybook 保留模拟 UI，本期产品不显示。
- 图片内容提取暂缓，Storybook 保留开关与状态，第一部分产品不显示该入口，不把图片提取能力作为验收条件；后续单独决定与模型能力的集成。
- 本次只核对源码，没有取得旧版窗口截图；视觉验收仍需逐项完成。
