# Agent 远程控制

## Why

让用户从手机管理桌面上正在运行的 XiaoWei Agent，并在桌面和远程端看到同一会话状态。该能力从 [Agent Chat](../archived/2026-09-28-agent-chat.md#后续提案) 的远程控制边界中拆出。

## What

远程客户端连接桌面宿主，复用同一 Agent 服务实例的会话读取、运行控制、事件订阅和问答／权限交互。首批开放方法与客户端范围待定。

## How

沿用现有设计边界。桌面宿主终止远程连接，建立可信调用身份和权限，通过一个逻辑连接转发请求、响应、状态事件和交互回应到同一 App Server 入口。沿用 Agent Protobuf／Gateway 业务契约，以获准的方法为开放范围。业务幂等 ID 跨传输保留，RPC 响应只返回发起端。

服务持有运行和会话状态，串行处理跨客户端的修改和问答／权限决定。断连后 Agent 继续运行，待答交互保持待答，重连通过新的订阅首帧恢复状态。工具使用的路径和产生的副作用归执行宿主。访问同一持久目录的独立宿主仍受 Journal 写锁约束。

## Current work

传输、配对与认证、版本和能力协商、设备身份与显示名称、离线设备清单和跨重启送达审计待设计。远程 CLI 是否纳入首批范围待定。
