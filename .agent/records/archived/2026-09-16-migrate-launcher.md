# 迁移 Launcher 搜索入口

## Why

用可唤起的搜索框替代初始化欢迎页，建立后续搜索能力共用的桌面入口。参考旧项目的交互，不引入内部后台依赖。

## What

本次范围是搜索框外观及窗口显示、隐藏、聚焦、快捷键与输入法处理。暂不迁移搜索数据源、结果列表、模式切换、剪贴板或 Agent 功能，也不引入 Rust。

## How

当前窗口、输入、定位与结果交互统一维护在 [搜索实现](../../../docs/search.md#launcher-搜索入口)。后续搜索能力由 [全局搜索事项](2026-09-16-migrate-search.md) 接入；快捷键扩展和来源焦点管理分别由 [快捷键事项](../active/2026-09-18-fixed-launcher-shortcuts.md) 与 [Tray、Dock 与焦点管理](../active/2026-09-28-tray-dock-focus.md) 承载。

迁移时选择透明窗口并关闭原生阴影，避免 macOS 原生阴影产生黑边；卡片圆角、边框和阴影由前端绘制。搜索框与结果容器分离，独立搜索框不显示结果分隔线。Electron/Node 承载窗口与宿主调用，原有 Rust 业务不迁写为 Node。

## Outcome

用户于 2026-09-16 确认当前搜索框样式：使用透明 Logo，右内边距 16px。组件层的 Esc 清空关闭、组合输入期间 Esc 不关闭、重新聚焦全选已在 Storybook 中验证 PASS；组合输入测试使用合成事件，不等于原生输入法验收。

已给桌面 Vite 增加与 Storybook 一致的 100ms 轮询。用户重启后确认窗口显示恢复正常，旧实例的 720 × 76 尺寸已更新为 800 × 71；Agent 未执行冷启动。固定全局快捷键已在 2026-09-18 获用户功能确认，见 [固定快捷键](../active/2026-09-18-fixed-launcher-shortcuts.md)。用户于 2026-09-18 确认 Launcher／搜索验收收尾项完成，原生失焦隐藏、拖动、屏幕定位和真实输入法不再列为待验收项；本事项实施完成，成果继续生效。

视觉样例与桌面共用 LauncherSearchBar，样式参数以旧版为基础，不保留此前新增的搜索图标和 Esc 标签；场景以组件旁的 Storybook 文件为准，验收流程见 [Renderer UI 开发](../../../desktop/src/renderer/README.md)。桌面与 Storybook 构建、`just check` 通过。

2026-10-07 按用户要求归档：原范围已实现并获验收确认，后续不再基于本事项进行重大改动。当前说明已按源码核对并沉淀至 `docs/search.md`；本 record 保留迁移理由、取舍与历史验收结果，归档不表示 Launcher 功能停止使用。
